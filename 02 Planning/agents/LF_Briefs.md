## Rules every lane follows

1. **Work only in your worktree** `E:\Projects\HCC\worktrees\<lane>` on branch `claude/<lane>`. Commit early and often; **never push**; never use bare `git stash`; never touch `.claude/launch.json`. New worktrees need the `03 Prototype\node_modules` junction to `E:\Projects\HCC\worktrees\fixwave-a\03 Prototype\node_modules` (remove it with `rmdir` before removing a worktree; never a recursive delete).
2. **Edit only the files in your ownership table** (below). A change needed elsewhere goes in your DONE file under "Integration needed" with the exact edit. Shared files only through the `// LF` append-only blocks: `handlers/index.ts` (`LF` object), `services/mock/index.ts`, `clients/sync/registry.ts`, `app/subscreens.ts` (your `// LF-<LANE>` block), `navmap.ts PAGE_CATEGORY`, `HccComposition.cs` (services and endpoints blocks), `Hcc.slnx` (your migration lines).
3. **Every build, test and check goes through the lock:** `pwsh -NoProfile -File "E:\Projects\HCC\worktrees\lf\tools\Invoke-Serialized.ps1" -WorkingDirectory "<your worktree>\03 Prototype" -Label <lane> -Command "npm test"` (likewise `npx tsc --noEmit`, `npm run build`, `dotnet build Hcc.slnx`, `dotnet test tests/<project> -maxcpucount:1 --logger trx`, `node tools/fit-screen-check.mjs --pages <yours>` with `PORT=<4190 + lane number>`). Exit 75 = busy: wait and run the same call again. Never filter test output; whole logs to `<worktree>\.scratch\` (uncommitted). Server lanes run only the test projects they touch; the full solution is the integrator's. One heavy job at a time on this PC; no emulator in any lane.
4. **Money and roles:** integer paise; GST from the dated master per line (CGST + SGST, half away from zero); simulated clock; fictional data; Owner-only money settings (DEC-058); Supervisor / Housekeeper / Maintenance / Tech admin / Restaurant never receive a money value (DEC-061, DEC-MA-11e — a test walks every new view); nobody approves their own request; a posted line on a closed day is never edited (DEC-077). No ID number, visa number or guest name of a real person in any file; no ID number in audit text, exports or messages.
5. **Layout (DEC-178…180):** every new desktop page is a `FitPage` with the named layout and its sub-screens registered; modals use `ModalFrame` with sticky actions; no font smaller than `main`, touch sizes ≥ 44 / 48 px; phone pages per the mobile rules (cards, 48 px, no sideways scroll at 360 px); colours as tokens (`node tools/themes.mjs --write` after a colour change). Your pages must pass `fit-screen-check.mjs` at the five viewports for every role that can open them before you write DONE.
6. **Migrations:** only your block (contract §11); `node "08 Production/tools/migrations-lock.mjs" --add` (`--docs --add` for the documents stream) and a `Hcc.slnx` line for each; never edit an applied one; RBAC seeds `*_rbac_seed.sql`; every table carries `property_id`, paise `BIGINT`, UTC `DATETIME2`, business dates `DATE`.
7. **Tests:** `03 Prototype/tests/stream-lf-<lane>.mjs` (`[LF-<LANE>]` names) for every guard in your contract sections; server tests in the project you touch; `npm test` and your server projects green before DONE; counts before / after in the DONE file. Fixture hash pins ([CAT] … [RMS]) and `accounting-golden.json` are the integrator's: if your lane moves FY26 on purpose, say so and leave the pins.
8. **DONE file** `05 Delivery Evidence/Legacy/LF-<LANE>-DONE.md` (template in `tools/README-agents.md` §4): commits, files, contract sections built, counts, open items, "Integration needed" with exact edits, the HANDOFF bullet, the check report path, 2–4 modal openers of your pages for `tools/fit-modals.json`. Write it even if you stop early.
9. **Contract beats guesswork.** A lane that finds the contract conflicts with the code, a decision or the old software's behaviour **stops on that item** and writes it in the DONE file; it never invents a business rule. A Sonnet lane that discovers it must touch money, GST, a posting rule or a permission stops and writes it for the coordinator (Build Plan §4).
10. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (Opus lanes) or `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (Sonnet lanes).
